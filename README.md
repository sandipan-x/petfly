# PetFly

Free tool: can your pet fly in the cabin? Check weight limits, carrier fit and compare 8 airlines' pet policies. No signup.

## Features
- Cabin eligibility check from pet + carrier weight with per-airline verdicts
- 8-airline compare deck: fees, weight limits and carrier sizes
- Flat-faced breed warning plus a pre-flight checklist
